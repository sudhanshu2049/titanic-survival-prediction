Dataset: Titanic (sample)

This folder contains a small sample of the Titanic passenger dataset used for model development and demonstration.

- `titanic.csv`: sample CSV with a handful of rows (PassengerId,Survived,Pclass,Name,Sex,Age,SibSp,Parch,Ticket,Fare,Cabin,Embarked).

Notes:
- Replace `titanic.csv` with the full dataset if you want to reproduce larger-scale experiments.
- The `src/` scripts assume the dataset is at `data/titanic.csv` relative to the repository root.
